**Swagger UI served from files in the repository (#1125)** — `/api-docs` served Swagger UI through `utoipa-swagger-ui`, whose build unpacks the release zip with the `zip` crate; on 2026-10-16 every `zip` release but 9.0.3 was yanked, so anything that resolves dependencies afresh failed, `cargo install nora-registry` without `--locked` among them. NORA now serves the same Swagger UI 5.17.14 files itself, byte for byte as the `swagger-ui-dist` package ships them, under the same paths and content types; `utoipa-swagger-ui`, `zip` and eight more packages leave the build. The source maps and unused bundles embedded before are gone, and the release binary is about 9.5 MB smaller.
