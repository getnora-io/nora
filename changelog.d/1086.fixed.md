**A pull of a locally pushed Docker image counts against that image (#1086)** — with an upstream configured, pulls of a pushed image were recorded under the upstream's namespace: the image's own metadata stayed at 0 pulls, and a stray namespaced metadata file hid its push date from curation's release-age check. Pull statistics now go beside the copy that was served. Stray `docker/<namespace>/<image>/manifests/*.meta.json` files left by earlier releases for pushed images can be deleted.
