**OIDC tokens were accepted without an audience check (GHSA-XXXX-XXXX-XXXX)** — a provider configured without `audience` accepted a token whatever its `aud` claim, so a token the same issuer minted for another service (GitHub Actions has one issuer for every repository) authenticated to NORA, and nothing was logged. Such a provider now stops the start and is refused on reload; see Changed.
