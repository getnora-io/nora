**npm tarballs from GitHub Packages are checked and cached as tarballs (#1069)** — GitHub Packages serves tarballs at `download/<@scope/name>/<version>/<sha1>`, a path without `/-/`, so NORA took it for a packument: curation did not run (an unlisted version was served under an allowlist), and the tarball was cached as metadata. Such a path is now that version's tarball: curation sees its version, and it is stored and served like any other tarball. Old entries under `npm/download/` are no longer used and can be deleted.
