**A release-age quarantine tightened by a reload was not applied (GHSA-54qr-w49h-mgfq)** — for PyPI and NuGet a `min_release_age` rule a SIGHUP reload brought in did not ask for release dates, so a fresh version the reloaded policy should withhold was still served. The rule now applies from the reload on, and a reload that changes `quarantine` or `quarantine_ttl`, which apply after a restart, logs a warning naming them.
