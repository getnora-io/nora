**The release SBOM files are signed (#1344)** — the four SBOMs a release carries (`nora-<tag>.sbom.{amd64,arm64}.{spdx,cdx}.json`) were attached unsigned: `cosign sign-blob` covered the binaries only, so an SBOM replaced next to an authentic binary could not be told from the release's own. Each SBOM is now signed by the release workflow (keyless Sigstore) and its `.bundle` attached beside it; every signature, binaries' included, is verified against the release workflow's identity before the release is published, and the post-release gate verifies the SBOM signatures. Verify one with `cosign verify-blob --bundle nora-<tag>.sbom.amd64.cdx.json.bundle --certificate-identity https://github.com/getnora-io/nora/.github/workflows/release.yml@refs/tags/<tag> --certificate-oidc-issuer https://token.actions.githubusercontent.com nora-<tag>.sbom.amd64.cdx.json`.
