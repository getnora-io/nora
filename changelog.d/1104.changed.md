**Reproducible builds: `--locked` everywhere, Swagger UI vendored (#1104)** — the Dockerfile dropped the `fuzz` workspace member with `sed`, which rewrote `Cargo.lock` and meant no build could pass `--locked`, so a `Cargo.toml` change merged without its lock update was re-resolved silently at image build time; the fuzz manifest is now copied (corpus stays out) and every cargo build, clippy, test and tarpaulin run in the Dockerfile and CI passes `--locked`. `utoipa-swagger-ui` now uses the `vendored` feature: the Swagger UI bundle served at `/api-docs` comes from a crates.io crate checksummed in `Cargo.lock` instead of a build-time GitHub download with no digest check.
