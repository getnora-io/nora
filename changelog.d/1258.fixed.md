**The dashboard says when a registry's upstreams are hidden (#1258)** — the Mount Points table showed `-` in the upstream column for a caller who is not signed in, the same as for a registry with no upstream, so a proxy that was configured and working looked unconfigured. The addresses stay hidden from such callers, as since #934. The column now reads "Hidden — sign in to see" where signing in is possible, or "Hidden" on an instance without authentication. `/api/ui/dashboard` says the same in a new `proxy_hidden` field per mount point. RPM and Debian upstreams, configured per repository, are reported like the other formats.
