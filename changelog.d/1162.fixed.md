**A store-side copy on Google Cloud Storage overwrites an existing object again (#1162)** — `object_store` 0.13 had the GCS copy modes swapped (apache/arrow-rs-object-store#712): an overwrite sent `x-goog-if-generation-match: 0`, so a copy onto an existing object failed with 412 Precondition Failed, and a create-only copy never refused. NORA now uses `object_store` 0.14, which sends the precondition only for a create-only copy. S3, local and in-memory storage were not affected.
