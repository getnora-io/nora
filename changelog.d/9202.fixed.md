**Readiness tells a full, read-only or silent store from a slow one** — `/health` and `/ready` no longer touch storage: they serve the verdict of the last maintenance tick (every 30 s), and a verdict older than 150 s counts as unreachable. On an object store the tick asks for the first page of a listing instead of listing the whole bucket, so a large bucket no longer keeps `/ready` at `503`; the store's size is counted apart. On the local disk the write probe creates a new file each time and passes only when the create, write, fsync and removal all do, so a read-only remount or a full disk turns `/ready` to `503` within one tick instead of passing on a file left from an earlier probe.
