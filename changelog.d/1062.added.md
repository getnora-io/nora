**npm: several upstreams routed by scope (#1062)** — `npm.proxies` sends each listed scope only to its own upstream, with its own Basic or Bearer credential (`auth_bearer_env`), and everything else to the default one; a private scope never reaches the public registry, not in metadata, tarballs, revalidation or audit requests. Cached objects record which upstream delivered them, and an owned scope is never served from a copy another upstream delivered.
