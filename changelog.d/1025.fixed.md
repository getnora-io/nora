**A fresh package install starts instead of crash-looping (#1025)** — the `.deb`/`.rpm` and `install.sh` defaults set `NORA_HOST=0.0.0.0` with no `NORA_PUBLIC_URL`, which validation rejects, so the service panicked (SIGABRT) and systemd restarted it every 5 s forever. The shipped defaults are now `NORA_HOST=::` (IPv4 and IPv6, falling back to IPv4 where IPv6 is unavailable) with `NORA_PUBLIC_URL=http://localhost:4000`, the same as the Docker image; set your real address for clients on other hosts. A configuration NORA cannot start with now exits with status 78 (EX_CONFIG) and a clear message instead of panicking, and the unit files carry `RestartPreventExitStatus=78`, so an existing install whose `nora.env` still has the old defaults stops once with the reason in the journal rather than looping.
