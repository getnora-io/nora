**The curation allowlist refuses downloads whose version NORA cannot read (#1067)** — the allowlist let a request without a version through as a metadata request, and a download whose file name NORA could not parse arrived without one. So an unlisted version was served whenever its name took an unfamiliar form (npm, PyPI, CPAN). Under an allowlist in enforce mode such a download now gets 403, with a reason naming the package; audit mode logs it. Metadata, indexes and raw files are unaffected.
