**A local-storage listing no longer reads the whole store (#1070)** — listing a prefix on the local backend walked every directory under the storage root and filtered the keys afterwards, so its cost grew with the size of the store: on a store of 100,000 files an npm packument cache miss took about 240 ms, and a path the upstream answers 404 (a miss on every request) timed out under 32 concurrent clients. The walk now starts at the directory the prefix names and returns the same keys as before for everything NORA stores.
