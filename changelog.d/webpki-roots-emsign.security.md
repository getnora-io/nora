**`webpki-roots` 1.0.9 → 1.0.11 (eMudhra emSign roots removed)** — reqwest is built with `rustls-tls`, so upstreams are verified against the roots compiled in from `webpki-roots`, not the system store. 1.0.9 still trusts `emSign ECC Root CA - G3`, the root above the revoked `EM DV TLS CA - G3B` intermediate, so an upstream (or a man in the middle) presenting a certificate from that chain was accepted. 1.0.10 removes the emSign G3 root, 1.0.11 also removes `emSign Root CA - C1` and `emSign ECC Root CA - C3` (Mozilla bug 2083709). A lock-only bump, no code change.
