**The curation allowlist checks GitLab-style scoped npm tarballs (#1058)** — a scoped tarball named in full (`@vendor/a/-/@vendor/a-1.0.0.tgz`, as GitLab's npm registry serves it) yielded no version, and the allowlist lets a request without a version through as a metadata request, so an unlisted version of a package proxied from such a registry was served. Both filename forms are now read, and an unlisted version is blocked.
