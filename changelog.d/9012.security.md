**An npm upstream's credential could follow a tarball redirect to another host (GHSA-54qr-w49h-mgfq)** — a tarball was fetched with the upstream's credential (`proxy_auth`, or a scope's token) through a client that dropped it only on a hop to another host or port, so when the upstream redirected a tarball to a storage host that redirected again within itself, that second hop carried the credential to the storage host. The credential now goes only while every hop is on the origin of the tarball URL (see Changed). If an npm upstream with a credential redirected its tarballs to another host, rotate the credential.
