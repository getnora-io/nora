**The Traefik example in `deploy/traefik.yml` no longer cuts a docker push at 60 s (#1197)** — its `websecure` entry point kept Traefik v3's default `readTimeout`, so a layer whose upload took longer than a minute was ended with `499` and the push failed. The example now sets `transport.respondingTimeouts.readTimeout: 0`; a deployment copied from it should add the same, or a value longer than its slowest push.
