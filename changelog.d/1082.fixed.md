**A configured rate limit is applied exactly (#1082)** — the `[rate_limit]` `*_rps` settings were converted to whole milliseconds per request, so any rate above 1000/s was applied as 1000/s and rates between 500 and 1000/s were rounded up (600 → 1000). The interval is now exact for every rate, and the defaults are unchanged. An instance configured with a rate between 500 and 1000/s now enforces it as written.
