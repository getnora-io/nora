**A command that exits on an error still writes its last log line (#1264)** — `NORA_LOG_FILE` was written from a queue that `process::exit` did not drain, so the line logged just before an error exit, usually the error itself, could be missing from the file. NORA now writes the file from its own thread and gives the queue about a second to reach the file before any exit, a return from `main` or a panic. A log file that takes no writes holds up no request and no shutdown. `tracing-appender` is no longer a dependency.
