**Curation files name registries as NORA does (#1092)** — a blocklist rule or an allowlist entry may name its registry in any case or by an alias NORA takes elsewhere (`PyPI`, `maven2`, `rubygems`); such entries used to match nothing. A registry name NORA does not know now fails the load, and so does an allowlist entry for every registry (`*`). In enforce mode a curation file NORA cannot load stops it with exit code 78, the configuration error the packaged systemd units do not restart into — it used to end in a panic, which they restarted every 5 seconds — and a reload keeps the previous rules; in audit mode the file is logged and skipped. Before upgrading a node that runs curation in enforce mode, check its curation files for registry names NORA does not know; rules that named a registry in another case or by an alias start to apply after the upgrade.
