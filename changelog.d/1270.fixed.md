**A `docker push` to a proxied name succeeds after a pull of the same image through NORA (#1270)** — after `docker pull` of an image through a proxied name, `docker push` of that image back to the same name failed: the client was told `Layer already exists` and then `manifest references an unknown blob` (`400 MANIFEST_BLOB_UNKNOWN`), although NORA held every layer. The layer probe found the copy the pull had cached under the upstream namespace, while the manifest check looked only under the bare name. The manifest check now looks up each layer and each sub-manifest of an index the same way the probe does, the namespaced copy and then the bare name, so the push is accepted.
