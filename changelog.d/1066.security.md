**The curation allowlist checks npm tarballs under a version directory (#1066)** — Font Awesome's npm registry serves `<name>/-/<version>/<name>-<version>.tgz`. That form yielded no version, and the allowlist lets a request without a version through as a metadata request, so an unlisted version of a package proxied from such a registry was served. The form is now read when the directory names the file's version, and an unlisted version is blocked.
