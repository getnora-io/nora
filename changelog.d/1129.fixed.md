A scheduled GC or retention pass that takes files out of the store (orphans, metadata phantoms, files evicted by `[gc] proxy_cache_max_bytes`, retention keys) marks the repository indexes stale, so the dashboard, `/api/ui/stats` and `nora_artifacts_total` / `nora_storage_bytes` count what is on disk. They used to count the deleted files until a restart or the next write to that registry. A dry run changes nothing.
