**Upstream addresses on the dashboard no longer show the credentials written into them (#1258)** — for a signed-in caller, a read-only token included, the Mount Points table and `/api/ui/dashboard` listed each upstream address as configured. An address written with credentials in it, such as `https://user:token@mirror.example/simple`, showed them in full. The addresses are now read by the URL parser the proxy client uses and shown without their `user:password@` part, in every spelling the client accepts. An address that parser cannot read is not shown. Credentials kept in the separate `auth` settings were never shown. If you wrote credentials into an upstream address, consider rotating them and moving them to the `auth` setting for that registry.
