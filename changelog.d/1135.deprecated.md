**`curation.mode` left at its default with proxy registries enabled is deprecated (#1135)** — such a configuration serves every upstream package unchecked. NORA still starts, but now logs a warning on every start naming the proxy registries, and `nora_config_deprecated{reason="curation_mode_implicit"}` is 1 so an alert can see it. From 1.5.0 it stops at startup: set `curation.mode` (`NORA_CURATION_MODE` or `[curation] mode`) to `off` to keep serving upstream packages unchecked, or to `audit` or `enforce`. An explicit `off` logs that upstream packages are served unchecked.
