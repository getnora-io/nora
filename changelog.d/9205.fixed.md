**Smaller fixes** — npm tarball links an upstream writes under the other scheme of its own host (an https registry behind a TLS terminator writing `http://`) are rewritten under NORA instead of sending the client past it; a RubyGems file name longer than any NORA serves is answered `400` before it is parsed, and parsing one of the longest servable length takes linear work; loading an htpasswd file warns once with the names of users whose hash can never match (a scheme other than bcrypt, an empty hash, a cost out of range), never the hashes.
